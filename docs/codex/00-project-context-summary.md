# 低代码平台项目上下文摘要

## 1. 产品定位
面向企业内部管理应用的低代码搭建与流程自动化平台。

## 2. P0 目标
支持企业通过低代码方式搭建合同管理、费用报销、采购申请三类真实业务应用。

## 3. P0 主闭环
应用创建 → 数据建模 → 表单配置 → 流程审批 → 权限控制 → 发布运行 → 数据沉淀 → 审计追踪。

## 4. 默认决策
- 首版优先私有化单租户
- 架构预留 SaaS 多租户
- 数据采用通用记录表 + JSON + 索引字段
- P0 不做完整 BPMN
- P0 不做完整 BI
- P0 不做插件市场
- P0 不做 AI 自动生成应用
- P0 移动端只做 H5 自适应
