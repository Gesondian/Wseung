## 4. 应用中心首页设计

### 4.1 页面目标

应用中心首页是所有应用的统一入口。不同用户只看到自己可访问、可管理或可设计的应用。

### 4.2 页面区块

| 区块 | 内容 | 对应功能点 |
|---|---|---|
| 顶部操作区 | 创建应用、从模板创建、Excel 创建、导入应用、进入回收站 | `P0-AC-007 ~ 009`, `P0-AC-019`, `P0-AC-022` |
| 搜索筛选区 | 关键词、状态、分类、关系、排序、卡片/列表视图切换 | `P0-AC-003 ~ 004` |
| 分类区 | 全部分类、一级分类、新建/编辑/删除分类、分类数量 | `P0-AC-005` |
| 应用列表区 | 应用卡片或列表，显示图标、名称、编码、状态、负责人、发布时间、更新时间 | `P0-AC-001 ~ 002` |
| 应用操作区 | 详情、设计、运行、发布、更多、移动分类 | `P0-AC-006`, `P0-AC-011`, `P0-AC-013 ~ 015` |
| 空状态 | 无应用时展示空白创建、模板创建、导入引导 | `P0-AC-001`, `P0-AC-007 ~ 009` |

### 4.3 状态表现

| 状态 | 页面表现 |
---|---|
| loading | Skeleton 或 Spin，不显示旧筛选结果。 |
| empty | Empty + 创建空白应用/模板创建/导入应用入口。 |
| no_result | 显示“暂无匹配应用”，保留清空筛选入口。 |
| permission_denied | 403 Result 或空列表提示“暂无可访问应用”。 |
| error | Alert + 重试按钮。 |

## 5. 应用创建向导设计

### 5.1 向导结构

| 步骤 | 内容 | 对应功能点 |
|---|---|---|
| 选择创建方式 | 空白应用、合同模板、费用报销模板、采购申请模板、Excel 创建 | `P0-AC-007 ~ 009`, `P0-AC-024` |
| 填写应用信息 | 名称、编码、图标、分类、描述、负责人 | `P0-AC-007 ~ 008` |
| Excel 解析预览 | 上传文件、表头识别、对象名、默认表单/视图开关、错误提示 | `P0-AC-009` |
| 确认创建 | 展示创建结果、进入应用详情或设计态 | `P0-AC-007 ~ 009` |

### 5.2 必须校验

```text
1. 应用名称必填。
2. 应用编码必填，且租户内唯一。
3. 负责人必须为 active 用户。
4. 分类必须存在且当前用户有权限。
5. 模板必须存在且版本可用。
6. Excel 文件格式、大小和表头必须可解析。
```

## 6. 应用详情页设计

### 6.1 页面目标

应用详情页是应用内设计、发布、运行、成员、日志和导入导出的统一管理入口。

### 6.2 页面区块

| 区块 | 内容 | 对应功能点 |
|---|---|---|
| 顶部摘要 | 应用名称、图标、状态、运行入口、发布入口、更多操作 | `P0-AC-011`, `P0-AC-014 ~ 018` |
| 基础信息 | 编码、描述、负责人、分类、创建人、更新时间、当前版本、最近发布人 | `P0-AC-010 ~ 011` |
| 资源统计 | 对象数、表单数、视图数、流程数、看板数、成员数、最近操作数 | `P0-AC-011 ~ 012` |
| 资源结构 | 数据对象、表单、视图、流程、权限、发布版本入口 | `P0-AC-012 ~ 013`, `P0-AC-015` |
| 成员入口 | 管理员、设计者、使用者、只读者概览和维护入口 | `P0-AC-020` |
| 导入导出 | 导出元数据包、导入元数据包、范围说明 | `P0-AC-021 ~ 022` |
| 操作日志 | 最近操作和独立日志入口 | `P0-AC-023` |

### 6.3 运行入口规则

| 应用状态 | 运行入口表现 |
|---|---|
| draft | 禁用或提示“应用暂未发布，请先完成发布后再访问运行端”。 |
| published | 有 `app.access` 权限时可进入运行态。 |
| disabled | 禁用或提示“应用已停用，暂不可访问”。 |
| recycled | 不可运行，必须先恢复。 |

### 6.4 设计入口规则

```text
1. 应用管理员、应用设计者、应用所有者可见设计入口。
2. 普通使用者和只读者不可进入设计入口。
3. 停用应用仍允许管理员进入设计入口。
4. 回收站应用不可进入设计入口。
```

## 7. 回收站设计

### 7.1 页面目标

支持查看软删除应用，并按权限恢复误删应用。

### 7.2 页面区块

| 区块 | 内容 | 对应功能点 |
|---|---|---|
| 回收站筛选 | 应用名称、删除人、删除时间、删除前状态 | `P0-AC-018 ~ 019` |
| 回收站列表 | 应用名称、编码、删除时间、删除人、删除前状态、当前冲突状态 | `P0-AC-019` |
| 恢复确认 | 恢复目标分类、编码冲突提示、恢复策略说明 | `P0-AC-019` |

### 7.3 恢复规则

```text
1. 只有具备 app.restore 权限的用户可恢复。
2. 应用编码被占用时必须阻止恢复并提示处理冲突。
3. 目标分类不存在时恢复到未分类或要求用户重新选择。
4. 恢复操作必须写审计。
```

## 10. 验收清单

### 10.1 Mock 验收

```text
1. `/apps` 可展示合同、费用报销、采购申请三个样板应用。
2. 应用卡片可区分草稿、已发布、已停用。
3. 搜索、筛选、排序、分类切换可用。
4. 空白创建、模板创建、Excel 创建入口可见，并能展示向导或 Mock 提示。
5. `/apps/:appId` 可展示应用详情、资源统计、资源结构、成员入口、导入导出和操作日志。
6. 草稿应用运行入口必须提示未发布。
7. 停用应用运行入口必须提示已停用。
8. 停用、恢复、删除操作有二次确认。
9. 回收站页面或入口可访问，并能展示恢复入口。
10. 导出提示必须说明不包含业务数据、流程实例、附件和审计日志。
```

### 10.2 真实联调验收

```text
1. 所有应用列表、详情、分类、成员、日志、回收站数据来自真实 API。
2. 创建、编辑、停用、恢复、删除、导入、导出、模板安装写入真实审计日志。
3. app.view、app.create、app.update、app.delete、app.restore 等权限由后端强制校验。
4. 运行入口加载真实 runtime pointer 和已发布快照。
5. 导入失败事务回滚，不产生半成品应用。
```
